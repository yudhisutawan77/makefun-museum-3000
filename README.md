A one-line museum label from the year 3000 for an ordinary object from today: a phone charger, remembered as a sacred nightly ritual.

Entry:

> Charger, 2024. Nightly, humans knelt by wall sockets and begged this white cord to resurrect their pocket oracle to 100%. The ritual was called 'charging'.

Run `python3 main.py` — it writes the label to `$ENTRY_OUT` (file or directory) and prints it to stdout.
